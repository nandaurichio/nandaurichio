# 🚀 Explorações Técnicas

Os projetos deste repositório representam diferentes etapas da minha jornada de aprendizado. Mais do que demonstrar ferramentas, eles mostram como utilizo dados para compreender problemas, testar ideias e desenvolver soluções.

## 📊 [Superstore](https://github.com/nandaurichio/projeto-superstore) 

Projeto de **Análise Exploratória de Dados (EDA)** utilizando **Python**, **Pandas** e **Matplotlib** para identificar padrões de receita, lucratividade e comportamento dos clientes.

**Competências desenvolvidas**

- Limpeza e preparação de dados
- Análise Exploratória de Dados (EDA)
- Visualização de Dados
- Storytelling com Dados



## 🎮 [Anagram Game](https://github.com/nandaurichio/anagram-game)

Projeto desenvolvido durante o **Code in Place (Stanford University)** utilizando **Python**, com foco em lógica de programação, estruturas de dados e resolução de problemas.

**Competências desenvolvidas**

- Python
- Estruturas de Dados
- Algoritmos
- Resolução de Problemas
